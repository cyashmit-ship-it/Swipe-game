# Photos

Put the photos in this folder with exactly these file names (lower case, `.jpg`).
Until a photo is here, the game shows a placeholder for it.

Portrait photos work best (about 3:4, at least 900 px tall). Keep each file under 400 KB so cards load fast on fest Wi-Fi.
Only use photos you have the right to use.
